## [Unreleased]

### Fixed
- **Affiliate coverage across all games (#47, money bug):** referral commission used to accrue only on crash + coinflip — referred play on the other 10 games earned referrers nothing. `creditReferral` now fires in every settlement transaction (the shared instant-settle + stateful-round paths, and the blackjack/jackpot/lottery engines), alongside `proofOfWager.accrue`. New `referral-coverage.spec.ts` source-scan guard maps every `GameType` to its crediting module (so a new game can't ship outside the affiliate program), plus an end-to-end `affiliate-settle.e2e-spec.ts` case proving a dice bet credits the referrer.
- **On-chain forged-event hardening (H5/H5a):** `verifyVaultTransfer` and `verifyTicketTx` now trust only `Program data:` events emitted while the configured program (vault / lottery) is the active invoke frame — a new `programScopedEventPayloads` walks the Solana log invoke stack (CPI-aware), so a look-alike program in the same transaction can no longer forge a Deposited/Withdrawn or TicketBought event. Gates real-money vault deposits + on-chain lottery tickets. `apps/api/src/solana/vault-events.ts`, `chain.service.ts`. Test: `vault-events.spec.ts` (forged-emitter + CPI-leak rejection).
- **Web hardening:** locked `images.remotePatterns` from wildcard `**` to `[]` (nothing uses next/image with remote hosts — the wildcard was an open, paid image proxy); added `robots.ts` + `sitemap.ts` (SEO scaffolding, scadium.com); tightened avatar `avatarUrl` validation to base64 raster images / http(s) / empty only, rejecting SVG and other script-capable data URLs (stored-XSS vector). Tests: `update-profile-avatar.spec.ts`.
- **Graceful shutdown:** `main.ts` now calls `app.enableShutdownHooks()`, so SIGTERM/SIGINT (every Railway/PaaS rolling deploy) runs the modules' `OnModuleDestroy` hooks — the crash/jackpot/lottery/blackjack engines release leadership and clear their loops, BullMQ stops, Prisma/Redis close — instead of an abrupt mid-round kill.
- **Crash client reconnect-resync (H16):** the crash hook now re-fetches `/crash/snapshot` on every socket (re)connect and authoritatively resyncs round state, so a WebSocket drop across the waiting→running transition (a rolling deploy / edge reset) can no longer leave `phase` stuck at 'waiting' and disable the cash-out button on a live bet. `apps/web/src/hooks/use-crash.ts`.
- **Log-redaction: geo proxy secret (H15):** `x-geo-proxy-secret` (the trusted-proxy credential that authenticates geo headers) is now in the pino redaction list, so it can't leak from logs and be replayed to defeat geoblocking. Test: `redaction.spec.ts`.
- **List-endpoint limit hardening:** a shared `parseLimit()` normalizes every `?limit` query param (NaN/blank→fallback, fractional truncated, clamped to [1,max]) across all 16 list controllers, so a `?limit=abc`/`?limit=1.5` can no longer reach Prisma's `take` as an invalid value. `apps/api/src/common/parse-limit.ts`.
- **Lottery play-money payout (H4):** in the default chain-disabled mode the settle now credits each winning ticket's lamport prize to the winner's play balance (`applyBalanceDelta`, ledgered). Previously tickets debited the play balance but every prize path no-op'd unless the on-chain lottery was enabled, so play-money winners were never paid. On-chain mode still pays $SCAD on-chain (gated, no double-pay). `apps/api/src/games/lottery/lottery.engine.ts`. Test: `apps/api/test/lottery-playmoney-payout.e2e-spec.ts`.
- **Product-copy honesty (H17):** corrected false marketing claims — landing "Audited: Yes" → "Pending" (audit is pre-engagement); six overstated RTP figures fixed to 95% (Limbo/Mines/Tower/HiLo/Wheel/Plinko; Dice 99% and Blackjack 99.5% are accurate and unchanged); removed "on-chain VRF" (no VRF exists — it's commit-reveal), the hero "On-Chain Games" tagline, the trade page's "every fill is a real transaction", and the promo bar's "on-chain AMM". Also fixed the `metadataBase` and affiliate referral URL from scadium.io → scadium.com.
- **Affiliate commission claim (H18):** accrued affiliate commission is now collectible — `POST /affiliates/claim` credits `(commission - claimed)` across the referrer's non-flagged referrals into their play balance under a Serializable transaction, advancing a new `commissionClaimedLamports` marker so each lamport pays once. Stats expose `claimableCommissionLamports`/`claimedCommissionLamports`. Migration `20260716120000_affiliate_commission_claimed`. Test: `apps/api/test/affiliate-claim.e2e-spec.ts`.
- **Hourly settle cadence (H11):** airdrop pool, staker dividends, block mining, and vault accrual now settle the last COMPLETED clock hour (`lastCompletedHourPeriod`) instead of the in-progress one. The worker fires every ~5 minutes, so previously each ran on only the first minutes of the current hour (and the airdrop then rejected tips for the rest of the hour). New shared helper in `queue.constants.ts`; applied to `airdrop.engine`, `airdrop.service`, `distribution.service`, `block-mining.service`, `vault-accrual.service`. Test: `queue.constants.spec.ts` + updated hourly e2e suites.
- **Blackjack betting-window restart (H1):** accepted bets are now persisted to the round's `stateJson` as they are placed/cleared during the betting window (`persistBettingStakes`), so a restart mid-window refunds them via boot recovery instead of finding an empty `{}` and confiscating the debited stakes. `placeBet`/`clearBet`/`leaveSeat` became async. `apps/api/src/games/blackjack/blackjack.engine.ts`. Test: `apps/api/test/blackjack-betting-recovery.e2e-spec.ts`.
- **Responsible-gambling limit bypass (H20):** coinflip `join` now passes the flip's stake and lottery `buyTicket` passes the ticket's lamport cost to `assertCanWager` (both previously passed `0n`, which short-circuits the daily wager/loss-limit check). A self-limited player can no longer bypass their limit by joining flips or buying tickets. `coinflip.service.ts`, `lottery.service.ts`. Tests: `coinflip.service.spec.ts`, `lottery-rg.spec.ts`.
- **Crash auto-cashout below bust (H3):** an auto-cashout whose target is below the committed bust point is now paid at that target regardless of 20 Hz tick granularity (previously a tick that jumped past bust made `cashOut` re-derive the live multiplier, see it >= bust, and throw — voiding the win). Payout also rounds instead of flooring (`Math.floor(m*100)` underpaid 0.01×). `apps/api/src/games/crash/crash.engine.ts`. Test: `apps/api/test/crash-autocashout-target.e2e-spec.ts`.
- **Seed-rotation fairness (C3):** `SeedManagerService.rotateServerSeed` now refuses (Serializable + active-round check) while any stateful round (mines/tower/hilo) is in progress, so a player can no longer reveal the active server seed mid-round to reproduce the committed layout and win deterministically. `apps/api/src/fairness/seed-manager.service.ts`. Test: `apps/api/test/seed-rotation.e2e-spec.ts`.
- **Coinflip cancel/join TOCTOU (H2):** `cancel()` now claims the flip with a guarded compare-and-swap (`updateMany where status='open'`) before refunding, mirroring `join()`. A cancel racing a concurrent join can no longer both refund the creator's stake and let the flip resolve (money duplication). `apps/api/src/games/coinflip/coinflip.service.ts`. Regression: `coinflip.service.spec.ts` cancel-CAS unit guard.
- **Blackjack money-integrity (C1/C2):** a rebet placed during the 5-second "settled" result pause no longer refunds the already-settled stake (money creation), and other seats' prior-round bets no longer ride the next round without a fresh debit. `apps/api/src/games/blackjack/blackjack.engine.ts` now clears every seat's bet when a new bet opens a round from the `settled` phase. Regression test: `apps/api/test/blackjack-rebet-settled.e2e-spec.ts` (red→green; existing blackjack suites still pass).
